# 入门练习

1. **什么是人工智能** 将阈值改为 120，比较 80、100 和 120。
2. **AI、机器学习与深度学习** 说明规则报警和鸢尾花模型的参数从哪里来。
3. **Python AI 开发环境** 执行 python -m pip show numpy scikit-learn，确认目录与版本。
4. **线性代数入门** 手算第二行的矩阵向量乘积。
5. **概率统计入门** 手算四个观测的总体方差与条件频率。
6. **导数与梯度入门** 从 2.4 继续做同一步长的一次更新。
7. **机器学习是什么** 指出分类示例的特征、标签和测试输出。
8. **监督学习与无监督学习** 为什么示例对簇大小排序？
9. **回归与分类** 预测 y=3x+2 在 x=20 时的结果。
10. **机器学习模型训练流程** 把标准化提前到拆分之前会怎样？
11. **模型评估基础** 若 95 个样本为负类，恒预测负类的准确率是多少？
12. **第一个机器学习项目** 把常数基线定义为测试集均值是否合理？
