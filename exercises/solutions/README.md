# 练习参考答案

1. **什么是人工智能** 输出依次为假、假、真。边界使用大于等于。
2. **AI、机器学习与深度学习** 阈值由开发者指定，分类模型的权重由训练样本与优化方法确定。
3. **Python AI 开发环境** 在激活的环境中应显示 NumPy 2.2.6 和 Scikit-learn 1.6.1。若位置不对，检查解释器。
4. **线性代数入门** 3×2 + 4×3 = 18。
5. **概率统计入门** 均值 2.5，平方偏差和 5，除以 4 得 1.25。条件下只有 3 和 4，频率 1/2。
6. **导数与梯度入门** 2.4 − 0.1×4.8 = 1.92。
7. **机器学习是什么** 4 个测量值为特征，品种为标签，测试输出为 30 个预测的准确率。
8. **监督学习与无监督学习** 聚类算法可以交换两个簇的编号，排序后仍能比较大小。
9. **回归与分类** 62。该示例无噪声，精度不能代表真实数据。
10. **机器学习模型训练流程** 测试数据影响均值和标准差，构成数据泄漏。
11. **模型评估基础** 95%，但正类召回率为 0。
12. **第一个机器学习项目** 不合理。预测时不能先知道测试标签，基线只能从训练集计算。
