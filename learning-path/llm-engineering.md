# 大模型工程路线

## 适合人群与前置知识

具备 NLP 入门和 HTTP 接口经验。

## 目标、顺序与关键技术

目标是能分别报告检索、回答质量和越权测试。

NLP → Tokenizer → Embedding → Attention → Transformer → LLM → Prompt → 模型 API → RAG 与向量库 → Reranker → Agent 与工具 → 部署 → 评估与安全。

关键技术：结构化输出、可验证的引用和工具边界。

## 实战与完成标准

构建离线评估可复现的检索系统。验收时能分别报告检索、回答质量和越权测试，记录环境、命令及输出。
