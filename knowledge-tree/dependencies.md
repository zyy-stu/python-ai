# 推荐依赖

1. Python 基础 → NumPy / Pandas 与数学基础并行 → 机器学习。
2. 机器学习 → 深度学习 → PyTorch → 计算机视觉或 NLP。
3. NLP → Attention → Transformer → 大语言模型 → Prompt 工程与 Embedding。
4. Embedding 与检索基础 → RAG。预训练原理是可选进阶。
5. 结构化输出与工具接口 → Agent。RAG 和 Agent 可独立学习，也可组合。
6. 模型部署和 AI 应用工程化可并行，统一以接口契约、评估和安全验证衔接。
