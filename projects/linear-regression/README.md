# 综合项目：预测工件加工用时

## 问题与数据

用工件数量预测加工秒数。生成 100 条记录，数量从 10 到 109，目标值为 12 加 2.5 倍数量再加标准差为 2 的独立高斯噪声。生成器与拆分均使用种子 42。唯一特征为数量，保留 20% 作测试。

## 运行

使用 Python 3.11+，安装根目录 `requirements-dev.txt`。运行 `python projects/linear-regression/main.py`。训练集拟合线性模型与均值基线，测试集只计算指标。预测新输入 60 件时，输出预计秒数。

## 实测与结论

```text
train_rows: 80
test_rows: 20
slope: 2.49115
mae: 1.39219
baseline_mae: 64.1931
r2: 0.999348
prediction_60: 161.814
```

测试 MAE 约 1.39 秒，低于均值基线的 64.19 秒。斜率约 2.49 秒每件，接近合成生成参数 2.5。该结果只适用于本教学数据及其拆分。生产数据还需验证时间泄漏、工况变化和样本外误差。
